🌿 Johar Jharkhand – A Digital Cultural Heritage Platform

🏆 Smart India Hackathon 2025 (Problem No. 32)
✨ A next-generation web platform to showcase, preserve, and promote Jharkhand’s rich culture & heritage using modern technologies like AR, Blockchain, MERN, and AI-powered integrations.

🌍 Vision

Jharkhand is known for its tribal culture, folk art, festivals, cuisine, and natural beauty. However, access to authentic cultural experiences remains limited.
Our platform aims to:

🎭 Digitally preserve art, dance, music, handicrafts, and traditions.

🏞️ Create immersive AR experiences of cultural sites.

🔗 Use Blockchain to ensure authenticity of cultural assets.

🌐 Build a scalable MERN web platform for global reach.

🤝 Connect artisans, tourists, and cultural enthusiasts in one ecosystem.

🛠️ Tech Stack
🚀 Core Technologies

MERN (MongoDB, Express.js, React.js, Node.js) 🟢

AR (Augmented Reality) for immersive heritage tours 🎨

🚀 Getting Started
1️⃣ Clone the Repository
git clone https://github.com/<your-team>/Johar-Jharkhand.git
cd Johar-Jharkhand

2️⃣ Install Dependencies

Frontend (React):

cd frontend
npm install
npm start


Backend (Node/Express):

cd backend
npm install
npm run dev


Blockchain (Smart Contracts):

cd blockchain
npm install
truffle migrate
